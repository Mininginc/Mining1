## Finding sent back to Coder (fixed)
- **FAIL: code.** The eBay importer (M4) wrote `platform.external_listings` (M1) directly. Moved behind `ExternalListingsService` in the M1 integrations hub.

## Spec clarifications (accepted)
- One part row per listing, with `quantity` equal to units available, instead of one row per unit. This keeps re-imports simple. The spec's data model already has `quantity`. Revisit when bins arrive (spec 1.3), where single units get their own locations.
- An unreadable cell becomes empty plus a review issue. The car is still imported.
