# ADR 0005: Built-in sign-in with roles and TOTP MFA
Status: Accepted (2026-11-27)

Phase 0 ships email + password sign-in (scrypt hashes), short-lived JWT access tokens (15 min default), role-based access, optional TOTP MFA (required for admin before Phase 1 go-live), and lockout after 5 failed attempts for 15 minutes. An external identity provider (Google Workspace / Microsoft) can be added later as another sign-in method without changing roles.
