# Spec 1.2: Vehicle intake (receiving, photos, VIN, title)
Status: **Outline, to be detailed after 1.1 is approved**
Module: M2 Vehicle Intake · Serves: Vehicle receiving (2), Initial photographs (2), Title processing and DMV documentation (3), Dispatch (3)

## Scope outline
- Yard app screen: scan or type the VIN, decode year/make/model (NHTSA vPIC adapter), assign stock number, print stock label.
- Take required photos (4 corners, odometer, VIN plate, interior), offline queue.
- Record purchase source, price, tow vendor and cost, title status.
- California paperwork checklist: title or salvage certificate, DMV Notice of Acquisition/Junk Receipt (REG 488C), NMVTIS report due within the reporting window, kept as documents on the vehicle.
- Vehicle statuses: purchased, in transit, received, inspected, being dismantled, stripped, crushed or sold.
- State rules stored as settings per state, so a second state is configuration, not code.

Acceptance criteria will be written once 1.1 is approved.
