# Spec 1.1: Bring in today's data (eBay inventory and the car spreadsheet)
Status: **Draft, needs Andrei's approval** (changes the roadmap: eBay sync moves from Phase 2 to Phase 1)
Modules: M4 Parts & Inventory (owner), M2 Vehicle Intake, M1 integrations hub (eBay adapter)
Serves: Inventory accuracy (4), Vehicle profitability (4), Marketplace management (3), Dismantling/inventory software (3)

## Why first
Today eBay is the parts inventory and Excel tracks each car. Every later Phase 1 screen (bins, picking, quotes, profitability) needs those parts and cars inside the platform. Without this, staff would keep two systems.

## Scope
1. **Car spreadsheet import (M2).** Upload the car productivity workbook (.xlsx or .csv). The importer shows a column-mapping screen once, saves the mapping, then creates or updates vehicles keyed by VIN. Fields: stock number (generated if missing), VIN, year, make, model, trim, purchase date, purchase cost, tow cost, delivered date, dismantled date, paid-off date, notes. Sales and costs totals are imported as **opening balances** on the vehicle, not as individual sales.
2. **eBay inventory import (M4), two sources.**
   - **2a. Seller Hub CSV (first, no API keys needed).** Upload the "Active listings" export from eBay Seller Hub. Sample: `fixtures/ebay-active-listings-sample.csv` (from Andrei, 2026-11-27). Columns used: Item number, Title, Custom label (SKU), Available quantity, Sold quantity, Format, Currency, Start price, Current price, Start date, End date, eBay category 1 name and number, Condition, eBay Product ID (ePID). Other columns (trading-card grading fields, UPC/EAN/ISBN) are ignored. The file starts with a UTF-8 byte-order mark; dates look like `Aug-28-25 16:15:35 PDT`; titles may start with an emoji.
   - **2b. eBay API (after the developer account is approved).** Connect the eBay seller account (OAuth). Pull all active listings: item ID, title, custom label (SKU), quantity, price, condition, category, item specifics (part number, interchange, fitment), photo URLs, listing date. Photos, item specifics and fitment come only from the API. Create one part per listing unit with status `listed`, and a `listing` record (M5 data, owned by the eBay adapter until M5 exists) linking the part to the eBay item.
3. **Link parts to cars.** Custom label format (confirmed by Andrei): `<car number>#<part name>`, e.g. `303#Rear Vent`. The car number is the vehicle stock number. Split on the first `#`, trim both sides; car number must be digits. No `#`, or an unknown car number, sends the part to the review queue. The title's year range, make and model (e.g. "1998-2003 OEM Jaguar XJ8") are kept as fitment text and used to flag a car-number mismatch (SKU says car 303, title make differs from car 303's make).
3a. **Quantity rules.** Available quantity > 0: that many units in stock, status `listed`. Available quantity 0 with the listing still active (eBay out-of-stock control keeps it alive after a sale): the listing is imported but creates no in-stock part; it is marked `out_of_stock` so it can be relisted when another unit is pulled. Sold quantity is recorded as history, not as new sales.
4. **Ongoing stock sync (one direction for now).** Every 15 minutes, fetch eBay orders and ended listings; mark sold parts `sold` and record the order as an external sale so inventory stays right. Pushing price and quantity changes to eBay comes with spec 1.4 (listings).
5. **Review screen.** Lists unmatched parts, duplicate VINs, rows that failed validation, and counts before/after. Re-running an import is safe (idempotent by VIN and eBay item ID).

## Out of scope
Creating or editing eBay listings, ShipStation, Car-Part.com, Monday.com data, the master pivot (finance comes in Phase 2), photos copied into our storage (we keep eBay URLs for now).

## Data
- `intake.vehicles`: id, stock_number (unique), vin (unique, 17 chars, check digit validated, warn only for pre-1981), year, make, model, trim, purchase_date, purchase_cost_cents, tow_cost_cents, delivered_on, dismantled_on, paid_off_on, opening_sales_cents, opening_costs_cents, source (`spreadsheet`|`manual`), notes, timestamps.
- `inventory.parts`: id, sku (unique), vehicle_id (nullable), title, part_number, interchange_number, condition, quantity, status, list_price_cents, photo_urls (text[]), source (`ebay_import`|`manual`), timestamps.
- `platform.integration_accounts`: provider, encrypted OAuth tokens, last_sync_at, status.
- `platform.external_listings`: provider, external_id (unique per provider), part_id, url, price_cents, quantity, status, raw (jsonb).
- `platform.import_runs`: kind, file name, started_by, counts (created, updated, skipped, failed), errors (jsonb).
- Every table carries `company_id` with row-level security (ADR 0006). Money in integer cents. Every write audited. Events: `intake.vehicle.imported`, `inventory.part.imported`, `inventory.part.sold_externally`.

## Acceptance criteria
1. Importing a sample workbook with 3 valid rows, 1 duplicate VIN and 1 bad VIN creates 3 vehicles and reports the 2 failures with row numbers.
2. Re-importing the same workbook changes nothing and reports 0 created.
3. The saved column mapping is reused on the next upload of the same layout.
4a. Importing `fixtures/ebay-active-listings-sample.csv` creates 3 listings for cars 303, 332 and 333, all `out_of_stock` (available quantity 0), with prices 55.00, 98.00 and 69.95 USD, start dates parsed with their Pacific time zone, and the emoji-prefixed titles kept intact.
4b. Re-importing the same CSV changes nothing.
4. After connecting a sandbox eBay account with N active listings, N parts exist with status `listed` and each links to its eBay item.
5. Parts whose custom label matches a known stock number link to that vehicle; the rest appear in the review queue.
6. When a listing sells on eBay, the part shows `sold` within one sync cycle, and the sale is recorded against the vehicle.
7. eBay tokens are stored encrypted and never returned by the API or written to audit rows.
8. Only admin and manager can run imports or connect eBay; warehouse and sales can view the review queue.
9. A failed eBay call (timeout, 5xx, expired token) is retried with backoff, logged on the import run, and never leaves half-imported parts.
